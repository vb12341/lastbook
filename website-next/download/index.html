Install on Mac

  1. Open Lastbook-1.1.19-mac.dmg.
  2. Drag Lastbook to Applications.
  3. Open Lastbook from Applications.
  4. Choose your library size, an optional local map, and optional local AI. Setup shows the space needed.
  5. Click Install and keep your internet connection on until setup finishes.
Apple security checks

Lastbook 1.1.19 is signed with our Developer ID and notarized by Apple. On first launch, macOS may ask you to confirm opening an app downloaded from the internet.

Once setup finishes, the library and AI work offline.

Install on Windows

  1. Download and run Lastbook-1.1.19-Setup.exe.
  2. Follow the installer, then open Lastbook.
  3. Choose your library size, an optional local map, and optional local AI in setup.

If Windows blocks the installer, contact hello@lastbook.org with the message you see.

Install on Linux

  1. Download the package for your Ubuntu: Ubuntu 24.04 or Ubuntu 26.04. To check which you have, run lsb_release -rs.
  2. In the folder containing it, run sudo apt install ./Lastbook_1.1.19_amd64.deb on Ubuntu 24.04, or sudo apt install ./Lastbook_1.1.19_ubuntu26.04_amd64.deb on Ubuntu 26.04.
  3. Open Lastbook from your applications menu and choose your library, state map and optional local AI.

Ubuntu 24.04 or 26.04 on Intel/AMD 64-bit computers. Setup downloads the content; Videos, Map and Chat work offline afterwards.
